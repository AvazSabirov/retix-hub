# Retix Hub — история версий клиента

Раздел текущей версии попадает в описание GitHub Release автоматически.

## 1.0.5

- **Автообновление, как у касс Retix:** новую версию загружает и публикует суперадмин («Обновления»:
  сразу, по расписанию, всем или выбранным компаниям). Программа узнаёт о ней из ответа сервера (и раз
  в 10 минут), скачивает установщик с докачкой, проверяет подпись сервера и SHA-256, ставит его тихо и
  запускается снова (в трее). VPN при обновлении не рвётся, Radmin и RDP не закрываются. Только по https.
- **Один вход — один компьютер:** токен входа регулярно меняется. Если вход скопировали на другой ПК,
  сервер это замечает и отключает ПК до одобрения администратором компании.
- «Выйти из сети» теперь отключает ПК и на сервере.
- Безопасность: «Пинг» больше не запускает `cmd` — имя чужого ПК не может выполнить команду на вашем.
- Безопасность: настройки от сервера проверяются (только сеть Retix Hub 10.66.0.0/16) — подменённый сервер
  не направит весь интернет через себя и не откроет общие папки всему миру.

Требуется обновлённый сервер. Версии до 1.0.5 обновляются вручную один раз — дальше сами.

## 1.0.4

- Подключение Radmin Viewer к Radmin Server на кассах через сеть Retix Hub (порт 4899):
  в меню правой кнопки «Полное управление», «Только просмотр», «Передача файлов», как в Radmin VPN.
  Radmin Viewer ищется сам (Program Files, реестр); если не найден — можно указать Radmin.exe один раз.
- Порт 4899 из подсети компании открывается в firewall Windows на каждом ПК.
- Если Radmin Server не отвечает, программа пишет возможную причину.

Требуется обновлённый сервер (открывает 4899 между ПК компании).

## 1.0.3

- Значок в трее целиком меняет цвет: зелёный — в сети, жёлтый — подключение, красный — VPN не работает.
- Кнопки «развернуть на весь экран» больше нет (окно меняет только высоту).
- Автозапуск при входе в Windows включается сразу при установке (окно — в трее).

## 1.0.2

- Окно в стиле Radmin VPN, темнее: кнопка ON/OFF, имя ПК, IP, статус, список компьютеров компании
  с полосками сигнала (онлайн сверху).
- Крестик и «свернуть» прячут программу в трей. Значок: зелёный — в сети, жёлтый — подключение,
  красный — VPN не работает. Повторный запуск программы показывает окно.
- Меню правой кнопки: Сообщение, Копировать IP-адрес, Пинг, Общие папки, Подключить сетевой диск,
  Удалённый рабочий стол, Свойства.
- Сообщения между компьютерами компании (через сервер, только внутри своей компании).
- Общие папки открыты между всеми ПК компании, как в Radmin. Если папки не открываются,
  программа пишет причину.
- Файл hosts больше не изменяется (Dr.Web блокировал запись).
- Кнопка OFF отключает VPN и остаётся выключенной после перезагрузки; ON подключает без пароля.
- Журнал рядом с программой: `C:\Program Files\RetixHub\logs\client.log`, падения — `crash.log`.
- Исправлены возможные падения программы (обращение к окну из фоновых потоков).

Требуется обновлённый сервер (сообщения и общие папки между всеми ПК).
