Настройки сети

По умолчанию ПК компании видят друг друга (ping), общие папки — те, к которым пользователь ПК сам открыл доступ, — и Radmin Server (порт 4899, подключение из Radmin Viewer).

С «любым трафиком» ПК связываются напрямую, мимо сервера — быстрее: в одном офисе — по локальной сети, в разных офисах — через интернет, если это позволяют роутеры. Если прямой путь не работает, трафик сам идёт через сервер.

Без этой галочки программа сама ставит на ПК RustDesk и настраивает его только для сети компании: подключиться можно лишь с других ПК компании, серверы RustDesk в интернете не участвуют. «С согласием» — пользователь ПК нажимает «Принять». «Без согласия» — подключение сразу, по одноразовому паролю, который выдаёт сервер Retix Hub. Каждое подключение — в журнале ниже.

С облаком RustDesk к ПК можно подключиться из любого места по его ID RustDesk (виден в списке компьютеров), как в обычном RustDesk: «С согласием» — пользователь нажимает «Принять»; «Без согласия» — по одноразовому паролю из окна RustDesk на том ПК или с нажатием «Принять»; «по паролю пользователя» — только по его паролю. Подключения через облако не проходят через Retix Hub и не попадают в журнал. Опасность: кто узнал ID и пароль (или уговорил пользователя нажать «Принять»), подключится из интернета — включайте, только если это нужно.

Пока удалённое управление включено, выключенный компьютер можно включить по сети — кнопка «Включить» в списке (Wake-on-LAN: его разбудит включённый ПК компании из той же локальной сети; пробуждение по сети должно быть разрешено в BIOS и настройках сетевой карты того ПК). ПК с отметкой «управляет» могут включать другие ПК и из программы.

Управлять другими могут только ПК с отметкой «управляет: да» в списке компьютеров (по умолчанию — ни один): только их пускает RustDesk на остальных ПК. Для отдельного ПК управление можно выключить или разрешить только с согласием. Пользователь ПК в программе («Управление → Доступ к этому компьютеру…») может сделать строже: только с его согласия, по его собственному паролю (его знает только он) или запретить.
